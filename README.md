# 一、指针基础


## 1. 什么是指针


指针：

> 存储变量地址的一种变量。


普通变量：

```text
保存数据
```


指针变量：

```text
保存地址
```


例如：

```c
int a = 10;

int* p = &a;
```


关系：

```text
a

↓

10


p

↓

a的地址
```


---

# 二、指针变量


## 1. 指针变量定义


格式：

```c
type* 变量名;
```


例如：

```c
int* p;
```


其中：

```text
int

表示指向的数据类型

*

表示这是一个指针变量
```


---

## 2. 指针初始化


例如：

```c
int a = 10;

int* p = &a;
```


其中：

```c
&a
```

表示：

> 获取变量a的地址。


```c
p
```

保存：

> a的地址。


---

# 三、指针访问内容


## 1. 解引用操作符


符号：

```c
*
```


作用：

> 通过地址访问地址对应的内容。


例如：

```c
int a = 10;

int* p = &a;
```


那么：

```c
*p
```


表示：

```text
访问a里面的数据
```


结果：

```text
10
```


---

## 2. p和*p区别


重点：

```text
p  = 地址

*p = 地址里面的数据
```


例如：

```c
int a = 20;

int* p=&a;
```


关系：

```text
&a

↓

p


*p

↓

20
```


---

# 四、通过指针修改变量


指针的重要作用：

> 通过地址修改变量。


例如：

```c
int a = 10;

int* p=&a;

*p=20;
```


执行后：

```text
a=20
```


原因：

```text
p找到a的地址

*p修改a里面的数据
```

&

# 六、const修饰指针


const作用：

> 限制数据修改。


主要有三种形式：

```c
const int* p;

int* const p;

const int* const p;
```


---

# 七、const int* p


也可以写：

```c
int const* p;
```


特点：

```text
p可以改变

*p不能改变
```


例如：

```c
int a=10;

int b=20;

const int* p=&a;
```


允许：

```c
p=&b;
```


不允许：

```c
*p=30;
```


原因：

const限制的是：

```text
*p
```


---

# 八、int* const p


特点：

```text
p不能改变

*p可以改变
```


例如：

```c
int a=10;

int* const p=&a;
```


允许：

```c
*p=20;
```


不允许：

```c
p=&b;
```


原因：

const限制的是：

```text
p
```


---

# 九、const int* const p


特点：

```text
p不能改变

*p也不能改变
```


表示：

```text
地址不能改变

内容不能通过指针修改
```


---

# 十、const指针总结


| 类型 | p是否可以改变 | *p是否可以改变 |
|---|---|---|
| int* p | 可以 | 可以 |
| const int* p | 可以 | 不可以 |
| int* const p | 不可以 | 可以 |
| const int* const p | 不可以 | 不可以 |
